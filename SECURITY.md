# Security Policy

## Supported Versions

Only the latest release receives security fixes. Please update to the newest
`ghcr.io/reimaris/smewlet` image before reporting.

## Reporting a Vulnerability

Please **do not open a public issue** for security problems.

Report privately through GitHub:
[Report a vulnerability](https://github.com/Reimaris/Smewlet/security/advisories/new)

Include the affected version, steps to reproduce, and the impact you see.
Never include real API keys, tokens or personal data in a report.

You can expect an acknowledgement within a few days. This is a
maintainer-run hobby project, so fix timelines are best effort.
